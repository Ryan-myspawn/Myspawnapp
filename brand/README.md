# MySpawn™ brand assets

Extracted from the site header lockup (icon mark + "MySpawn™" wordmark, Outfit 800).

| File | Format | Size | Use |
|---|---|---|---|
| `myspawn-logo-horizontal.png` | PNG, transparent | ~2246×450 | Primary logo on light backgrounds (site header, docs, email) |
| `myspawn-logo-horizontal-white.jpg` | JPEG, white bg | ~2630×786 | Where a solid background is required (some social/press uploads) |
| `myspawn-logo-horizontal-dark.png` | PNG, navy bg | ~2630×786 | Logo on dark backgrounds (dark headers, dark social banners) |
| `myspawn-icon.png` | PNG, transparent | 512×512 | Icon-only mark (favicons, app tiles, compact spaces) |
| `myspawn-icon-white.jpg` | JPEG, white bg | 512×512 | Icon on solid white |
| `myspawn-avatar-1024.png` | PNG | 1024×1024 | Square social profile picture (X, Instagram, LinkedIn, etc.) |

## Colors
- Ink (wordmark "My"): `#1B2735`
- Indigo (wordmark "Spawn", icon): `#6055AC`
- On dark, "Spawn" uses lavender `#C7D2FE`
- Trademark "™" is black `#000000` on the light/white lockups, light on the dark lockup

## Note on resolution
The icon mark originates from a **256×256 raster** source, so the transparent/white
icons are exported at 512 and the avatar at 1024 to stay crisp at real display sizes
(web headers, social avatars). For large-format print or billboard use, a **vector (SVG)
redraw** of the helix mark is recommended — ask and it can be produced.
