# MySpawn Evidence Standards
*Binding on every content agent (Longpost Studio, Content Factory AM/PM, SEO Writer, Deep Production, Trend Radar, Competitor Watch). Purpose: nothing MySpawn publishes can be dismissed as false news. In a trust business, sourcing IS the marketing.*

## The source hierarchy (cite the highest tier available)
1. **Peer-reviewed papers** — link the journal page or DOI (Nature, NEJM, Nature Communications, Human Reproduction, Cell Reports Medicine, etc.). Name journal + year in the text, not just the link.
2. **Clinical trial registries** — ClinicalTrials.gov NCT IDs linked directly (e.g. Gameto Phase 3 = NCT06858111).
3. **Official/institutional** — FDA documents, university press offices (OHSU, Cambridge, CHOP), regulator releases (HFEA, NY AG), company SEC filings.
4. **Named reputable journalism** — STAT, MIT Technology Review, Science, WaPo, Bloomberg, TechCrunch, Fortune. Name outlet + date in text.
5. **Primary X posts** — link the actual x.com/status URL when available; quote VERBATIM with the date. If the post is only known via coverage, cite the coverage and say so ("as reported by Slate"). Never upgrade a paraphrase into a quote.
6. **Aggregators/blogs** — last resort only, labeled ("per Longevity.Technology"), never for a load-bearing claim.

## Hard rules
- **Minimum per article/script:** 3 sources, at least 1 from tiers 1-3 for any science claim.
- **Label epistemic status in the text**: "peer-reviewed" / "preprint, not yet peer-reviewed" / "company announcement, unverified" / "reported, unconfirmed". Company PR ≠ science.
- **Verify links** before publishing: fetch each URL where the environment allows; if a page can't be directly fetched, mark it "(via search index — verify before posting)" in the internal file version. Never cite a link you invented from memory without verification.
- **Numbers**: never invented, never rounded into a stronger claim. When sources conflict, give the range and cite both.
- **Dates on everything**: every quote, statistic, and event gets its date. Old quotes labeled as old (e.g. Musk's anti-DINK quote is Dec 2023 — say so).
- **Real people**: verbatim public statements only, linked; react to the idea, not the person; no AI likenesses of real people; defamation check — would this sentence survive the person reading it with a lawyer?
- **Known fakes registry (never cite as real):** "EctoLife" (CGI concept, Hashem Al-Ghaili 2022), the Chinese "pregnancy robot"/Kaiwa (AI-generated hoax, debunked by Snopes/Live Science). Usable only as labeled debunks.
- **MySpawn's own claims**: storage only; never promise descendant creation; IVG has produced NO mature human gametes; GenVault's accreditations are GenVault's, not MySpawn's.

## Per-platform sourcing format
- **[X]**: 1-2 load-bearing links inline; append a "Sources:" reply-thread block (listed at the end of the article file) with all links.
- **[FACEBOOK]**: end with "Sources in first comment" and provide the ready-to-paste first comment listing all links.
- **[REDDIT]**: inline links at the exact claim (Reddit fact-checks live); include an honest "what we don't know yet" line — it inoculates against the top skeptical comment.
- **Blog/SEO**: inline links + a References section.
- **Video scripts**: sources as on-screen citation callouts noted in [SHOT] directions + a source list in the file for the description box.

## Corrections policy
If any published claim later proves wrong: next run's email opens with a CORRECTION block (what was wrong, what's right, source), and the platform post gets a visible correction. Corrections are brand-positive in this category — issue them fast and plainly.
